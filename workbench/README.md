# Development workbench

Keep reviewed, human-authored WSUP drafts and temporary analysis here when they
are useful to maintainers. Promote accepted decisions and procedures to
[docs](../docs/); do not keep competing canonical copies.

Use ignored `.work/` for session logs, disposable investigations, and local
implementation notes. Keep generated check reports in `.wsup/reports/`.
Never place credentials, restricted records, or private captures in this folder.
Review and sanitize drafts before staging; nothing is committed automatically.
