# Plan work

Inspect enough source, local guidance and project ownership to ground the plan.
State the outcome and relevant constraints. Separate known facts, assumptions
and unresolved decisions. Consult connected local context before asking for
information already available.

Break work into coherent, reviewable outcomes. Name the owner of each change,
real dependencies, verification and any necessary migration or recovery work.
Use proportional detail: a small edit need not become a multi-phase programme.
Keep reversible local preparation ahead of consequential external actions.

Resolve routine choices using evidence and existing authorisation. Ask focused
questions for missing decisions that materially change the result. Clearly label
proposal-only steps. A plan does not grant permission to commit, publish, deploy
or perform other unrequested actions.

Completion means the sequence can be executed, each outcome has an observable
verification condition, and blockers or assumptions are explicit. If implementation
is also authorised, proceed into the plan rather than repeatedly seeking approval.
