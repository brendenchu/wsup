# Journaling

For an authorised recap, read the existing entry and journal guidance before
writing. Use journal/YYYY/MM/YYYY-MM-DD.md with ISO timestamps and an explicit
local timezone/offset. Use journal/TEMPLATE.md for new entries.

Record material outcomes, decisions, actual verification, blockers and useful
follow-ups. Distinguish user decisions, Git authorship, assistant execution and
unknown attribution; task delegation does not establish personal authorship.
Separate proposed, uncommitted, committed and deployed work. Append corrections
without silently changing historical claims. Link canonical evidence with its
owner and exclude secrets. Keep updates concise and avoid duplicate entries.

Routine automatic journaling is an optional workspace policy, not implied by
installing this kit. No background collection or external publication is enabled.
