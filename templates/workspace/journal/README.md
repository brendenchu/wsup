# Workspace journal

Use YYYY/MM/YYYY-MM-DD.md entries and the local TEMPLATE.md. Select a timezone
explicitly and record ISO timestamps with their actual offset. Distinguish user
choices, Git authorship and assistant execution. Record only observed outcomes,
actual checks and known limits. Keep canonical evidence with the owning project;
link sanitised summaries here. Do not copy secrets or private captures.

Journal maintenance does not authorise commits, publication or deployment.
