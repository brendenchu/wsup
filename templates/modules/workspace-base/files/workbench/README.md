# Workbench

Use this area for human-authored drafts, temporary analysis, and working notes.
Review and sanitize material before tracking it. Never place credentials or
restricted records here. Promote approved content to its canonical owner.

Use ignored `.local/` for local session notes, plans, handoffs, and investigation
evidence. Create it only when needed. Ignored does not mean disposable, backed
up, or confidential; preserve useful work and promote maintained knowledge.
