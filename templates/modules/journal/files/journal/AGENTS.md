# Journal

- One file per day at `journal/YYYY/MM/YYYY-MM-DD.md`, following
  [TEMPLATE.md](TEMPLATE.md), with ISO timestamps and an explicit local
  timezone offset.
- Append updates; correct earlier claims by appending, never by silently
  rewriting them. Avoid duplicate entries.
- Attribute user decisions, Git authorship, and assistant execution separately;
  delegating a task does not establish personal authorship. Label work as
  proposed, uncommitted, committed, or deployed.
- Link evidence with its owner; exclude secrets and restricted personal data.
