# Recap work

Read the local journaling rule and existing daily entry. Establish the date and
timezone from user context; state uncertainty rather than inventing timestamps.
Inspect only relevant owner histories and observed work.

Append one concise update covering material decisions, changes, actual verification
and remaining work. Attribute conversation decisions and Git authorship separately
from assistant execution. Keep canonical evidence with its owner and link it.
Use the workspace's existing journal directory; create it on demand if absent
and journaling is appropriate. Use a local template if one exists; otherwise
include decisions, changes, actual verification, and remaining work under a
timestamped update heading. Preserve previous entries.

Completion means claims have evidence, proposed/uncommitted work is labelled and
sensitive data is omitted. A recap does not authorise code changes, commits,
external messages, publication or background collection.
