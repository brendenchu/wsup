# Private storage planning

This scaffold provides documentation only, not protected storage. It does not
change permissions, ACLs, Git ignore rules, indexing, sync, or backup settings.
Do not add restricted records until the owner has approved and verified those
controls. Prefer approved storage outside a broadly scanned workspace.

A folder name and an ignore rule do not provide confidentiality. Keep private
records out of Git, generated reports, and shared bundles, and verify an
appropriate encrypted backup and recovery process separately.
